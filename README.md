# Pips Ledger

Shared trade journal for the Funding Pips $5K and $10K accounts. Next.js 14 + TypeScript + Supabase.
Setup steps are in `Pips-Ledger-Setup-Guide.pdf`.

Quick start: copy `.env.example` to `.env.local`, fill the Supabase keys, run `supabase/schema.sql` in the Supabase SQL editor, then `npm install && npm run dev`.
